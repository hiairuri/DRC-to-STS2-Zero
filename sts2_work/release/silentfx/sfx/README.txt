刃雨毒潮SilentFX 0.72.7

为静默猎手卡牌提供视觉特效与补充音效，不修改战斗规则或游戏结果。

音效来源

本模组不携带《杀戮尖塔2》的音频。附加音效从玩家已安装的游戏音频库中按需读取；音乐处理也使用游戏运行时已有的 FMOD。若游戏更新导致音频库或接口变化，相关处理可能不可用，模组会记录原因并继续运行。

可选地，将自己的 <音效名>.ogg 或 <音效名>.wav 放在本机模组目录的 sfx 文件夹中，文件会覆盖该名称的默认声音。请勿分享或发布未经授权的游戏音频。

设置与个人选择

支持 RitsuLib 的设置页，但 RitsuLib 是可选项。没有安装它时，模组仍可运行；设置保存在模组目录旁的 user_settings.ini。音效候选和单声音微调保存在 sfx/choices.ini。它们是本机个人配置，不属于发布包。

新安装没有 choices.ini 时，音效使用模组内置的默认候选。游戏更新或重装模组时，请保留自己的 user_settings.ini、choices.ini 和自带音频文件。
